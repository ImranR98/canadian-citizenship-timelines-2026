About

This dashboard visualizes Canadian citizenship application timelines extracted from the r/ImmigrationCanada megathread. Comments are scraped from Reddit and processed by an LLM to extract structured timeline data including application dates, processing stage completion dates, and applicant metadata.

Date columns show average wait times (in days) from the application date for the currently filtered subset.

Disclaimer: This is an unofficial, community-sourced project. It is not affiliated with, endorsed by, or connected to Immigration, Refugees and Citizenship Canada (IRCC) or the Government of Canada. All data is self-reported by Reddit users and may contain inaccuracies.
