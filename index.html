About

This dashboard visualizes Canadian citizenship application timelines extracted from the r/ImmigrationCanada megathread. Comments are scraped from Reddit and processed by an LLM to extract structured timeline data including application dates, processing stage completion dates, and applicant metadata.

Date columns show average wait times (in months) from the application date for the currently filtered subset.
